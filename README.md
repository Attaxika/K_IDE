K_IDE.py is a lightweight IDE designed for Python 2.7 for UNIX-based operating systems that have the Gnome-Toolkit(3) bindings
No attribution is necessary for programs made with K_IDE, but re-distributing/repackaging without any functional changes is explicitly disallowed.

v0.3b is for Python 3+, bindings are incorrect & code modifications need to be made to make the program functional again. This project is pretty much abandoned, but the version for 2.7 is still available and works
